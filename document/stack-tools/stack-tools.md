# Comparativa de Tecnologías Backend y Frontend

## BACKEND

| Lenguaje / Framework     | Ventajas                                                                 | Desventajas                                                                 |
|--------------------------|--------------------------------------------------------------------------|------------------------------------------------------------------------------|
| **Java (Native)**        | - Rápido y robusto<br>- Multiplataforma (JVM)<br>- Estándar empresarial | - Verboso<br>- Curva de aprendizaje media<br>- Alto consumo de memoria      |
| **Java (Spring Boot)**   | - Modular y escalable<br>- Gran comunidad<br>- Integración con servicios | - Configuración compleja<br>- Pesado para apps simples                      |
| **Python (Native)**      | - Simple y legible<br>- Ideal para prototipos<br>- Bueno para automatizar| - No apto para apps web grandes sin framework<br>- Bajo rendimiento relativo|
| **Python (Django)**      | - Completo y seguro<br>- CRUD rápido<br>- Admin incorporado             | - Menos flexible<br>- Curva de aprendizaje moderada                         |
| **C# (Native)**          | - Buen rendimiento<br>- Tipado fuerte<br>- IDEs poderosos                | - Dependencia de entorno<br>- Comunidad más cerrada                         |
| **C# (Entity Framework)**| - ORM potente<br>- Soporte LINQ<br>- Migraciones fáciles                | - Abstracción compleja<br>- Puede ser lento en grandes volúmenes            |
| **PHP (Native)**         | - Fácil de aprender<br>- Compatible con servidores<br>- Amplio soporte   | - Código propenso a desorden<br>- Escalabilidad limitada                    |
| **PHP (Laravel)**        | - Moderno y expresivo<br>- Estructura MVC<br>- Gran comunidad            | - Mayor consumo de recursos<br>- Requiere arquitectura clara                |

---

## FRONTEND

| Tecnología     | Ventajas                                                                 | Desventajas                                                                |
|----------------|--------------------------------------------------------------------------|----------------------------------------------------------------------------|
| **Native (HTML/CSS/JS)** | - Control total<br>- Ideal para proyectos simples<br>- Sin dependencias     | - Difícil de escalar<br>- Falta de estructura                              |
| **Angular**    | - Robusto y empresarial<br>- Basado en TypeScript<br>- Buen soporte      | - Curva de aprendizaje alta<br>- Verboso                                   |
| **Vue.js**     | - Simple y ligero<br>- Fácil de aprender<br>- Reactividad excelente       | - Ecosistema menos maduro<br>- Fragmentación arquitectónica                |
| **React**      | - Virtual DOM<br>- Alta popularidad<br>- Ideal para SPAs                 | - Solo cubre vista<br>- JSX confuso para principiantes                     |
| **Ionic**      | - Multiplataforma<br>- Usa tecnologías web estándar                      | - Depende de WebView<br>- Rendimiento limitado para apps grandes           |
| **Flutter**    | - Alto rendimiento<br>- UI coherente<br>- Hot reload                     | - Aprende Dart<br>- Apps pesadas<br>- Comunidad en crecimiento             |
